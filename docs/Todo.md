## 녹화 기능

| 기능 | 사용 예시 | 우선 |
|---|---|:---:|
| 영역 지정 녹화 | 화면에서 필요한 사각형 영역만 드래그해서 녹화 | ① |
| 녹화 영역 기억 | 이전 영역이나 1920×1080 등의 규격 재사용 | ① |
| 전역 단축키 | 다른 프로그램을 사용하는 중에도 녹화·정지·일시정지 | ① |
| 시작 카운트다운 | 3초·5초 뒤 녹화 시작 | ① |
| 작은 녹화 컨트롤바 | 시간·정지·마이크 상태를 화면 한쪽에 표시 | ① |
| 자동 종료 | 30분 경과 또는 지정한 파일 크기에 도달하면 종료 | ② |
| 예약 녹화 | 지정한 날짜와 시간에 녹화 시작 | ② |
| 최근 구간 저장 | 버튼을 누르면 직전 30초·1분을 영상으로 저장 | ③ |

## 소리와 카메라

| 기능 | 사용 예시 | 우선 |
|---|---|:---:|
| 시스템 소리 + 마이크 동시 녹음 | 프로그램 소리와 내 설명을 함께 녹음 | ① |
| 소리 크기 표시·개별 조절 | 마이크가 꺼졌거나 소리가 너무 작은지 확인 | ① |
| 웹캠 화면 삽입 | 화면 모서리에 발표자 얼굴 표시 | ② |
| 오디오 트랙 분리 | 내 목소리와 시스템 소리를 녹화 후 따로 조절 | ② |
| 잡음 제거·음량 보정 | 팬 소음 줄이기, 목소리 크기 일정하게 맞추기 | ② |
| 말할 때 배경음 줄이기 | 설명하는 동안 음악이나 시스템 소리를 자동으로 낮추기 | ② |
| 카메라 배경 제거 | 인물만 남기거나 배경을 흐리게 처리 | ③ |
| 특정 앱 소리만 녹음 | 시연하는 앱의 소리만 포함 | ③ |

| 커서 크기·색상 변경 | 고해상도 화면에서도 포인터가 잘 보이게 표시 | ① |

| 특정 영역 집중 표시 | 주변을 어둡게 하고 설명할 부분만 강조 | ② |
| 자동 확대·축소 | 클릭하거나 조작하는 부분을 자연스럽게 확대 | ② |

## AI 및 차별화 후보

아래는 기존 기능을 조합해 ClipDock의 특징으로 발전시킬 만한 아이디어입니다.

| 기능 | 사용 예시 | 우선 |
|---|---|:---:|
| 한국어 자동 자막 | 음성을 자막으로 만들고 SRT·VTT로 저장 | ② |
| 자막으로 영상 검색 | “설치 경로”라는 말을 한 위치로 바로 이동 | ② |
| 무음·실수 구간 편집 제안 | 긴 침묵이나 반복 발화를 찾아 삭제 후보 표시 | ③ |
| 요약·챕터 초안 | 긴 설명 영상의 목차와 요약 생성 | ③ |
| 조작 과정 → 매뉴얼 | 주요 화면과 설명을 모아 단계별 안내서 초안 생성 | ③ |
| 오류 제보 패키지 | 재현 영상·설명·사용자가 선택한 환경 정보를 묶어 내보내기 | ② |
| 개인정보 가림 제안 | 이메일 등으로 추정되는 부분을 찾아 사용자가 확인 후 가리기 | ③ |
| 로컬 AI 처리 선택 | 지원되는 자막·분석 기능을 PC 안에서 실행 | ③ |
