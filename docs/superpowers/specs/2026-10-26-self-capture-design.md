# ClipDock 자기 창 캡처 정책

사용자가 승인한 방향: 캡처 제외 기본 켜기 + 자동 최소화는 별도 선택.

- 녹화 설정에 `ClipDock 창을 녹화에서 제외`(기본 true), `녹화 시작 시 최소화`(기본 false)를 추가하고 이 두 값만 QSettings에 저장한다. 이슈 #2의 전체 품질/영역 설정 복원은 별개다.
- Windows 10 2004 이상에서 미리보기 준비부터 녹화 마무리까지 앱 소유 메인 창과 Qt 대화상자에 캡처 제외를 적용한다. 대기 상태에서는 해제하여 앱 스크린샷을 찍을 수 있게 한다. 실패/미지원은 UI로 알린다.
- 미리보기는 최소화하지 않는다. 제외되지 않은 메인 창이 캡처 화면/영역과 겹치면 동영상 대신 중첩 방지 안내를 표시한다. 다른 모니터나 영역 밖으로 이동하면 미리보기가 돌아온다. 포털의 실제 대상은 알 수 없으므로 보수적으로 처리한다.
- 선택적 자동 최소화는 화면 권한·공유 선택과 첫 프레임 확인 및 출력 준비가 끝난 뒤, 인코더를 시작하기 직전에 적용한다. Starting 진입만으로는 화면 권한 준비를 보장하지 않는다. 제외 요청이 미지원/실패하고 영역이 겹치면 이때 최소화를 대체 동작으로 적용한다. 작업 표시줄에 창은 남겨 단축키가 실패해도 다시 열 수 있다.
- 대체 동작 중 녹화 영역에 창을 복원하거나 이동·크기 변경으로 겹치면 일시정지한다. 재개 시 다시 최소화한다. 앱이 자동 최소화했던 창만 종료/시작 실패 후 원래 일반/최대화 상태로 복원한다. 권한 대기, 미리보기, 저장 대화상자 취소 때는 최소화하지 않는다.
- 이번 작업에 작은 컨트롤바, 네이티브 macOS 캡처 백엔드, Linux 포털 확장은 포함하지 않는다.

검토한 방식: 캡처 제외만으로는 플랫폼 제약이 있고, 최소화만으로는 미리보기/조작이 불편하다. 두 방식을 조합한다. 기존 Windows 검증 코드와 현재 기능 브랜치를 이어서 수정한다.
