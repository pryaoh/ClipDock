# 녹화 설정과 영역 복원 (#2)

사용자가 다음 작업 1번의 실행을 요청했다. 기존 Qt 6.8/C++20 앱에서 반복 녹화 설정을 보존한다.

- 출력 크기, FPS, 비트레이트, 코덱, 오디오 장치 ID, 마지막 저장 폴더를 QSettings에 저장한다.
- 마지막 영역은 모니터 이름/제조사/모델/일련번호, 화면 내부 논리 좌표, 논리 크기, 배율과 함께 저장한다.
- 모니터 인덱스와 전역 좌표는 영구 식별자로 사용하지 않는다. 일련번호가 있으면 우선 사용하고, 없으면 이름/제조사/모델의 유일한 일치만 허용한다. 중복 식별자, 장치 소실, 크기/배율 변경 및 경계 밖 영역은 복원하지 않고 재지정을 안내한다.
- 설정 오류는 항목별 기본값으로 복구한다. 사라진 오디오 입력은 녹음 안 함, 지원하지 않는 코덱은 사용 가능한 MP4 코덱으로 대체한다. 없으면 시작을 막고 안내한다.
- 영역 모드 재진입도 마지막 영역을 재사용한다. 창 핸들은 저장하지 않고 재실행 시 화면 모드로 시작한다. Wayland 대상 선택은 계속 포털에 맡긴다.
- 파일 메뉴에 설정 초기화를 추가한다. 대기 상태에서만 적용하며 녹화 파일은 건드리지 않는다. 기존 캡처 제외/최소화 옵션도 기본값으로 되돌린다.

## 접근 방식
기존 QSettings 직접 접근을 MainWindow에 모두 넣으면 검증과 모니터 조합 테스트가 UI에 결합된다. 별도 JSON 파일은 기존 저장 방식과 중복된다. 따라서 QSettings 읽기/쓰기와 순수 모니터 매칭을 RecordingPreferences 모듈로 분리하고 MainWindow는 사용자 변경 및 복원 연결만 담당한다. 이는 구현 담당자의 선택이다.

## 검증
임시 INI 저장소에서 저장/새 인스턴스 복원, 손상 데이터, 코덱/오디오 소실, 모니터 순서 변경/중복/음수 배치/해상도와 DPI 변경을 검증한다. MainWindow에서 재생성, 영역 재진입, 초기화, 저장 대화상자의 폴더 사용 및 취소를 회귀 검증한다. 실제 물리 다중 모니터와 타 OS 실행은 #3에 유지한다.
